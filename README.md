# Crowns & Cards — исходный проект игры

Это **многофайловая версия** Crowns & Cards. Она сделана из последней версии игры с лабораторией, боем 16×16, паками, бестиариями и магазином. Внешний вид и игровая механика на этапе переноса намеренно не менялись.

## Как запустить

1. Распакуйте `Crowns-and-Cards-project.zip` в любую папку на компьютере.
2. Если установлен Python 3, откройте терминал в папке `Crowns-and-Cards` и выполните:

   ```bash
   python -m http.server 8000
   ```

   В Windows команда может выглядеть как `py -m http.server 8000`.
3. В браузере откройте `http://localhost:8000/`.
4. Для остановки сервера нажмите `Ctrl+C` в терминале.

Можно попробовать открыть `index.html` двойным щелчком, но запуск через локальный сервер надёжнее при дальнейшей разработке. Для работы с кодом удобно использовать **Visual Studio Code**.

## Структура проекта

- `index.html` — разметка экранов и подключения CSS/JS.

- `css/20-world-hero-and-equipment.css` — экран «Мир», герой, экипировка и слоты отряда.
- `css/30-collection-and-squad-cards.css` — оформление карт и выбора бойцов.
- `css/40-bestiaries-and-packs.css` — бестиарии и паки.
- `css/50-tactical-battle-and-laboratory.css` — поле 16×16 и лаборатория.
- `js/00-core-and-data.js` — первоначальное ядро игры, коллекция, сохранения, данные существ и героев.
- `js/10-sidebar-navigation.js` — навигация по боковому меню.
- `js/20-expeditions-and-navigation.js` — выбор походов.
- `js/30-hero-selector.js` — портрет и выбор героев.
- `js/40-equipment-and-shop.js` — экипировка и магазин предметов.
- `js/50-world-squad-slots.js` — четыре слота отряда.
- `js/60-collection-card-presentation.js` — внешний вид карточек.
- `js/70-bestiaries-and-map.js` — экран бестиариев и карта мира.
- `js/80-pack-cover-controller.js` — изображения и оформление паков.
- `js/90-tactical-battle-16x16.js` — пошаговый изометрический бой.
- `js/95-laboratory-fusion.js` — бесплатное слияние существ.
- `assets/` — изображения карт, героев, фонов, символов, походов и паков. Ресурсы хранятся отдельно от кода.

## Важное про разработку

Это **первый этап модульного перехода**, а не полная перепись игры. Мы разделили HTML, CSS, JS и картинки по файлам **без изменения игровой логики**. В старом ядре `00-core-and-data.js` ещё объединены несколько функций, а часть стилей содержит исторические переопределения. Их лучше очищать постепенно, с регрессионными тестами, чтобы не сломать действующую игру.

**Порядок подключения скриптов важен.** Если менять названия или порядок JS в `index.html`, некоторые функции могут перестать работать.

### Сохранение прогресса

Прогресс хранится локально в браузере. Для `http://localhost:8000` и файла `file:///.../index.html` браузер использует разные области хранения. Если вы раньше играли через отдельный HTML-файл, старые сохранения могут не появиться автоматически в локальной версии. Не удаляйте исходный файл с прогрессом до проверки.

Для командной работы проект удобно выложить на GitHub, чтобы сохранялась история изменений.

## Проверка файлов

В корне проекта запустите `python tests/check_project.py` (в Windows — `py tests/check_project.py`). Проверка покажет, что подключаемые файлы и ресурсы находятся на своих местах. Для полной проверки нужно вручную запустить игру в браузере и пройти несколько боёв.
