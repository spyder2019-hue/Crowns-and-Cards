# Как обновлять Crowns & Cards

Игра опубликована через GitHub Pages из ветки `main`. Не редактируйте `main` напрямую для обычных изменений игровой логики.

## Ветки
- `main` — стабильная версия, которая отображается игрокам.
- `develop` — рабочая ветка для новых возможностей, проверок и исправлений.

## Порядок обновления
1. Внесите изменение в `develop` (лучше отдельным небольшим коммитом).
2. Проверьте проект локально: `python tests/check_project.py` и `node --check js/имя-файла.js`.
3. Откройте GitHub → **Pull requests** → **New pull request**: `base: main`, `compare: develop`.
4. Дождитесь зелёной проверки **Check Crowns & Cards / Files and JavaScript**.
5. Протестируйте игровые действия вручную в браузере: паки, лабораторию, армию, бой и сохранения.
6. Только после этого нажмите **Merge pull request**. GitHub Pages развернёт обновление из `main`.

**Важно:** автоматическая проверка ловит отсутствующие файлы и синтаксические ошибки JavaScript, но не гарантирует исправность боя и других механик — их нужно дополнительно проверять в браузере.

## Сохранения
Прогресс игры сейчас хранится в `localStorage` браузера. Изменение адреса сайта, очистка данных или использование другого устройства может привести к отсутствию прежнего прогресса. Не очищайте данные сайта, пока не сделана резервная копия.

## Что стоит добавить потом
- Автоматические браузерные тесты игровых действий.
- Экспорт и импорт сохранений.
- Номер версии и список изменений.
- Предрелизный стенд для `develop`, отдельный от публичного сайта.
